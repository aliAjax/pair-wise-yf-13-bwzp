# hxyfront-62001 船舶轮机备件更换台

面向船舶轮机班的备件更换登记台。预置 4 台设备与 6 件备件，按班次登记领用、拆下旧件与安装新件，旧件回收入库后生成入库回执并解除设备只读。

## 业务规则（整次拒绝，原库存与设备状态不变）

- 领用数量超过库存 → 整次拒绝
- 同一设备旧件未拆下就登记安装新件 → 整次拒绝
- 同一设备上一周期旧件未回收入库 → 禁止再次领用，整次拒绝
- 本班仍有挂账设备（旧件未回收入库）→ 不得完成交接

## 代码结构（业务数据 / 校验规则 / 页面分离）

```
src/
  domain/
    types.ts   业务数据模型
    seed.ts    预置数据：班次、4 台设备、6 件备件
    rules.ts   校验规则（纯函数）
    store.ts   状态仓库：先校验后落账 + 浏览器存档（localStorage）
  pages/
    WorkbenchPage.tsx  工作台页面
    panels/            库存、设备、操作台、交接班、筛选、异常时间线、操作流水
```

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62001

数据保存在浏览器 localStorage，刷新保留，并跨标签页实时同步；「重置存档」可恢复预置数据。
