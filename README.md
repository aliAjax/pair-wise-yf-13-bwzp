# hxyfront-62001 船舶轮机备件更换台

面向船舶轮机值班的备件更换工作台：按班次登记领用、拆下旧件与安装新件，旧件回收入库闭环，交接班留痕。

## 业务规则

- 预置 **4 台设备**（主机、发电机#2、主海水泵、分油机）与 **6 件备件**（按设备适配）。
- 更换登记为**整次事务**：领用数量超过库存、同设备未拆先装、旧件未回收入库（设备挂账只读）任一发生即**整次拒绝**，原库存与设备状态不变，并记入异常时间线。
- 登记成功后设备转入**挂账（只读）**；在「设备与库存」登记**备件入库回执**后工单闭环、设备解除只读。
- **本班仍有挂账设备不得完成交接**；交接完成后班次自动顺延。
- 筛选条件、异常时间线与业务台账均同步至浏览器存档（localStorage），**刷新保留**。

## 目录结构（业务数据 / 校验规则 / 页面分离）

```
src/
  data/seed.ts        # 业务数据：班次、预置设备与备件、初始台账
  domain/types.ts     # 领域类型
  domain/rules.ts     # 校验规则（纯函数）：登记 / 回执 / 交接
  domain/store.ts     # 状态迁移（先校验后落账）+ localStorage 存档
  pages/              # 更换登记、设备与库存、异常时间线、交接班
  App.tsx             # 外壳：班次、指标、页签、存档同步
```
